cta-ridership-predictor/

python · xgboost · scikit-learn · pandas · streamlit

End-to-end ML pipeline forecasting daily ridership across 144 CTA 'L' stations using 23 years of Chicago Open Data Portal records. Engineered leakage-free time-series features and validated with walk-forward cross-validation. XGBoost achieved 13.6% MAPE and R²=0.94 on a 6-month held-out test set — 2.3× lower error than naive baselines. Deployed via interactive Streamlit dashboard.

uic-cs-rag-agent/

python · anthropic claude · chromadb · bm25 · streamlit

RAG system answering questions about the UIC CS department (60+ courses, degree programs, contact info). Implements three retrieval strategies — dense embeddings, BM25 keyword scoring, and hybrid Reciprocal Rank Fusion — with course-code-aware tokenization to handle ambiguous queries. Grounded refusal pattern via Claude prevents hallucination; every answer cites its source chunks. Evaluated against a hand-curated benchmark.
